## 🚀 نصب و اجرا

### پیش‌نیازها
```bash
pip install flask flask-cors pandas yfinance
```

### راه‌اندازی سرور
```bash
python app.py
```

### دسترسی
- مرورگر: `http://localhost:5000`
- API: `http://localhost:5000/api`
